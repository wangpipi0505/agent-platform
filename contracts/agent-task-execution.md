# R-36 单步 AGENT 任务执行

任务请求成功受理后，单步 AGENT 任务使用任务归属主体及受理时绑定的应用发布版本创建一条真实运行。运行、入口步骤和分派关联在同一短事务内提交。模型和工具调用由既有运行调度器在提交后执行。

同一任务只允许关联一条入口运行。任务行锁和分派唯一键保护并发重放。执行结果按现有分派租约 owner 和 generation 提交，终态来自运行事实。取消与执行结果竞争时保持先落库的终态，并阻止已取消任务继续派发新调用。

本卡覆盖直接提交且无计划、无上游依赖的单步 AGENT 任务。已有会话、计划推进与跨任务依赖各沿用自己的契约。

该入口使用已发布的对话应用，未指定输入时使用任务目标作为消息。门户换票先查询发布版本元数据，再换发绑定该版本与摘要的任务服务票。引擎兼容现有任务受理时的发布标识，提交前核对运行与任务的版本和摘要一致。未声明工具范围时继承发布授权，显式数组按精确版本引用收窄，越界时拒绝建立运行。
