# L0～L3 接入分级

分级定义以 `contracts/assistant-integration.md` §2 为准；本文只给选择方法与落地步骤。

| 等级 | 平台交付 | 宿主前提 | 对业务源码的改动 |
| --- | --- | --- | --- |
| L0 独立助手 | 已发布应用的受控独立入口、统一登录、可配菜单链接 | 已有菜单/导航入口 | 无（但必须明示是独立页面，不得冒称原页面弹窗） |
| L1 配置式嵌入 | 受控 iframe 页面或 SDK 挂载配置 | 已有扩展位/组件槽；部署人员配置来源与 CSP | 无页面逻辑改动，需部署配置 |
| L2 最小前端接入 | 固定版本 SDK + 宿主按钮 `open()` + 标准 provider 短票 | 一处 script/组件挂载与按钮绑定 | 少量前端改动，**不是零代码** |
| L3 最小身份适配 | 通用身份协议适配或同源票据代理 | 原生身份接口、合法服务账号、网络/授权配置 | 通常由平台承担；确需宿主改动时单列原因/接口/兼容范围/责任人 |

## 如何选择

1. **先问有没有菜单/扩展位**：没有、也不能改页面 → 先交付 L0；不要用 L1/L2 的验收口径冒充。
2. **能插一个按钮**：选 L2，用本包的 SDK 与短票 provider；这是最常见路径。
3. **连按钮都不能加、但有 iframe 槽**：选 L1，按 `examples/iframe-host.html` 与 `host-checklist.md` 的 CSP/`frame-ancestors` 配置。
4. **宿主有原生身份、希望免登录**：在 L2/L1 之上加 L3；身份来源必须是平台批准的有 限协议（可信身份查询或标准签名令牌），不允许任意脚本鉴权。

## L2 最小步骤

1. 平台管理员创建接入档案（`/admin/integration-profiles`）与配置发布（`/admin/config-releases`），得到 `appCode`、`integrationId`、激活环境。
2. 宿主后端增加同源短票接口（见 `examples/bff/ticket-server.mjs`）：从服务端会话取已验身份，调用平台 `/embed/ticket`；浏览器只收到短期票据。
3. 页面引入固定版本 SDK（`assistant.js`，见 `versions.md` 的 checksum），用 `init({endpoint,appCode,integrationId,ticket,autoLauncher:false,onHostEvent})`。
4. 宿主按钮调用 `handle.open()`；关闭用 `handle.close()`；页面上下文用 `handle.updateContext()`。
5. 监听 `result` 事件，只用其中已校验的 `businessRecordRefs`，并由宿主后端重新鉴权后做只读查询；**不得**把“模型输出”当作业务已提交。

## L1 最小步骤

1. 配置平台侧 iframe 入口与允许来源（`allowedOrigins` 精确匹配，不允许通配）。
2. 宿主页面 `<iframe src="https://assistant.example.com/w/{appCode}" allow="clipboard-write">`，`sandbox` 按需最小化。
3. 宿主在 `load` 后向 iframe 发送 hello（`agent-platform:assistant:hello`，带一次 nonce 与实例 ID），接收方必须校验 `event.origin`、`event.source`、nonce、实例 ID 与 `schemaVersion`。
4. 只接受 §4.1 声明的七类事件；未知 schemaVersion/事件忽略并记录，不执行任何导航或脚本。

## L3 身份适配

- 门户/原生身份路径复用 Authority 与 portal session；新增身份源只允许平台批准的有 限协议（可信身份查询或标准签名令牌），字段映射、audience/issuer、租户/应用/环境上限、过期与撤权写入接入档案。
- 缺可信身份时必须返回可解释阻塞（`INTEGRATION_IDENTITY_PROVIDER_UNAVAILABLE`），**不得**降级 dev、服务高权或共享 operator。
- 已知限制：IAM 模式下网关入站边界只放行固定路径（运行/会话/状态/事件），`/embed/ticket` 不在放行集；该模式的短凭据是 Authority 签发的 portal session。BFF 短票示例适用于非 IAM 的可信 BFF 模式；详见 `deploy/integration/README.md` 的「已知限制」。

## 安全边界（全等级）

- 浏览器不得接收集成 ApiKey、模型密钥、vault 或 Authority 凭据；票据不得进 URL/日志/localStorage/可导出配置。
- 客户端不能决定 tenant/角色；pageContext 不改变 Actor，只做显式声明的业务上下文。
- 服务端只回短期运行票据；票据绑定 tenant+principal+app+integration+environment 上限与有效期，origin 精确匹配。
- 缺失/过期/撤权时按 `error-codes.md` 的可解释码返回；不要用「重试即成功」掩盖身份问题。
