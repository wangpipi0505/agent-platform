## 0. 读法与判定规则

1. **两个等级体系，不得互换**：
   - **接入等级 L0～L3**：`contracts/assistant-integration.md` §2，描述宿主以何种方式接入平台（独立入口 / 配置式嵌入 / 最小前端接入 / 最小身份适配）。
   - **验证证据等级 L0～L4**：三路线验证方案 §0.1，描述“实测到了哪一步”。本文件引用时一律写作“证据等级 Lx”，避免与接入等级混淆。
2. **声明一个等级成立 = 三项同时成立**：平台交付存在 + 宿主前提成立 + 该等级证据成立。缺任一项记 **BLOCKED**，不得用低等级证据冒充高等级，也不得用“代码已写”冒充“已落地”。
3. **当前无任何经本批次核验的 `ACTIVE` 接入档案（IntegrationProfile）或 `ACTIVE` ConfigRelease**。本文件不写具体 `releaseId/profileId`，不以历史验证环境或旧配置代替；授权后由管理员按 `configuration-profile.md` 创建并核验。
4. **`PUBLISHED` 只表示技能/应用版本的发布状态**，不等于该路线分级落地完成，也不等于任何业务场景验收通过。
