# Actual fixed-version source reading

All files below are copied/downloaded inside this new project only. `manifest.json` records each actual byte SHA, origin URL and (where applicable) previously frozen local source. No adjacent project was inspected. These are targeted source reads, not claims to have read entire projects.

- Spring Framework 6.2.7 (Apache-2.0): AbstractPlatformTransactionManager.handleExistingTransaction checks isolation only when validateExistingTransaction is enabled; default REQUIRED participation can otherwise join a lower isolation transaction. MaterialScopeStore inspects the real bound JDBC connection and accepts RR/SERIALIZABLE; no REQUIRES_NEW and no global isolation change.
- Spring Framework 6.2.7 (Apache-2.0): DataSourceUtils.doGetConnection/isConnectionTransactional uses the connection holder keyed by the same DataSource; prepareConnectionForTransaction sets explicit isolation. createPublished requires actual write transaction, same DataSource resource, no auto-commit, transaction-owned connection.
- Spring Framework 6.2.7 (Apache-2.0): DataSourceTransactionManager.DataSourceTransactionObject extends JdbcTransactionObjectSupport and its isRollbackOnly delegates to ConnectionHolder. ResourceHolderSupport.setRollbackOnly persists that flag. createPublished marks precisely that holder when throwing, so an enclosing caller catching the exception cannot commit a partial run. It does not create a compensating transaction or suppress the original exception.
- Jackson databind 2.19.0 (Apache-2.0): JsonNodeDeserializer._fromFloat chooses getDecimalValue with USE_BIG_DECIMAL_FOR_FLOATS; otherwise JSON numeric floats can go through getDoubleValue. _fromBigDecimal handles zero/trailing-zero normalization. MaterialScopeStore reparses actual PG JSONB text with BIG_INTEGER/BIG_DECIMAL, normalizes privately, and hashes sorted object/ordered array/nested null/exact values. No global Json changes.
- Spring Security 6.5.0 (Apache-2.0): NimbusJwtDecoder.decode rejects PlainJWT, calls createJwt (jwtProcessor.process), then validateJwt before returning. TrustedJwtDecoder's fixed local scope exception runs only after that sequence and existing identity/timestamp/profile checks.
- Nimbus JOSE JWT 9.37.3 (Apache-2.0): DefaultJWTProcessor.process(SignedJWT) verifies JOSE typ, obtains configured key candidates, verifies signature and only returns claims on successful verification. No local capability grants a signature or profile bypass.

New invariants are commented in RunAuthorityStore, MaterialScopeStore, RunAuthority, ServiceRoutePolicy and TrustedJwtDecoder. The LoopbackAuthority Grant originalCall is finite test fixture state, preserved across resume/forward/approver; no production IAM server is claimed.
