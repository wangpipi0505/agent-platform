# AP 纯前端可写演示状态补齐

日期：2026-11-05。范围仅为明确启用的 mock 模式；未修改任何后端生产实现。

## 实现

- `web/shared/mock-state-extensions.ts`：模型供应商及条目 CRUD、自检、凭据引用与配额；提示词模板插值、草稿版本与发布快照；技能分类、当前业务身份可见性、配置范围、CRUD、引用检查、版本发布与合同演示检查。
- 应用列表按实际查询参数 `q/code/domain/bizCategory/tag/status/type` 筛选。版本目录为独立快照，提供版本详情、差异、恢复草稿与默认版本激活。恢复推进草稿修订，激活保留历史；新发布版本按历史最大编号递增。初始治理 v1/v2 分别冻结简洁/详细响应配置。
- 发布预检生成当前候选摘要，评测报告同时绑定应用、草稿修订、摘要；无匹配通过报告时预检显示阻断，提交再次核对预检身份。
- `web/shared/mock-runtime-extensions.ts`：FLOW 新建图与已保存图运行；正式运行读取发布图快照；调试运行 ID、数值游标、节点事件、单步挂起、暂停序列校验与控制修订；流程审批衔接；评测报告返回 UI 使用的候选、所有者、逐用例结果与汇总；运行中心概览、告警评估及确认。
- `web/shared/mock-onboarding-extensions.ts`：命名输入保存/修订/删除、提升为冻结评测集并保留用例标识与断言；连接/环境/接入档案、体验、配置发布写入由状态扩展提供；模板预检发布、接入会话计划与四步骤推进；统计按当前运行集合派生，保存后读取独立统计快照。
- `web/shared/mock-transport.ts` 接入扩展与上传 helper；新增集合纳入 sessionStorage。接入用户治理应用/技能/场景、正式与对话入口、业务身份和权限接口、运行快照、双阶段审批及恢复。保留原始请求中的附件和参数供父任务最终接线。未知路径继续返回 404/405。

## 演示限制

- mock 候选摘要为确定性 64 位十六进制指纹，供本地候选绑定；不作为生产密码学证明。
- FLOW 执行是有界串行模拟，依据保存的节点、边、简单条件与控制 Mock 前进；无实际模型、网络、生产授权及外部业务写入。
- 评测使用输入派生的演示输出并比较预期值，非真实模型评测。发布预检显式标记 `NON_PRODUCTION/DEMO`。
- 用户治理的业务规则、双阶段审批与执行前读回由独立 `user-governance.ts` 提供；规划附件与制品最终异步注册接线由父任务接续。
