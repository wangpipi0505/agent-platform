# G2 对账、重试许可与取消后续实施分解（未实现）

按冻结详设册20 F6、册31 F7/W1–W3/取消隔离推进。HTTP SUBMIT_QUERY 和签名 CALLBACK 是前置局部路径，不能据其绿测关闭本阶段。原契约正文和逻辑调用幂等键不改。

## 未生效的重试许可

- 技能侧只记录外部 APPLIED / NOT_APPLIED / UNKNOWN 与来源证明，不自行重新提交。查询必须取原绑定 job/key，并先验证当前权限覆盖原范围；无响应、错归属、含糊状态均保持 UNKNOWN。
- 本地 NOT_SENT 证明仅在发送 CAS 已被可靠栅栏阻止时成立；send_started=true 不可按网络异常猜未发送。外部 NOT_APPLIED 则须明确配置的查询标记及原 key/job 证据，不能把普通404/5xx当许可。
- 引擎通过内部 HTTP 取不可变证明，验证 tenant/principal/run/node/call/attempt/版本/合同/args/key、原状态、证明摘要和当前审批。短事务生成单次重试许可与新 attempt；重复操作 requestId 返回同结果，不生成多代、不跨HTTP持锁。已取消/终态/新代/参数变化/证明冲突均拒绝。
- 技能执行器只有看到引擎 REGISTERED 的新代和绑定的 NOT_APPLIED 许可才可归档旧事实/绑定并开始新发送；UNKNOWN 普通重入、重复 execute/outbox 或适配器查询都不重发。逻辑callId与幂等键保持，同call最终仅一次逻辑提交，旧代回调只留痕。
- 原确认仅在相同技能版本/参数、仍有效且角色合法时复用；参数变化必须走新确认。模型预算、实际外调时长与各attempt账务不能因重试而清零，统计仍按逻辑callId去重。

## 取消三态

- 请求受理、外部停止、效果撤销是独立事实；本地 run=CANCELLED 不证明另外两项。未知以明确 UNKNOWN/未证实表示，不能默认 false 或 true 冒充核实结论。
- 取消先在引擎原子阻止后续认领/逻辑提交，再持久登记每个原调用的取消指令；事务外调用技能中心，按原 tenant/run/call/job/key 精确传播。重复取消与服务重启不重新创建外部业务。
- 各适配器只按声明且经验证的停止接口/状态确认外部停止；HTTP200受理不等于停止完成，cancellable=false/未实现协议明确 UNSUPPORTED，不用断本地连接假装撤销。效果撤销只有独立可验证证据才能标成功，不自动编造补偿动作。
- 取消与提交/回调/NOT_APPLIED许可并发按统一 run→node→call 锁顺序和代次CAS处理；迟到事实保留但不能复活取消运行。ANY 汇合只取消专属剩余分支，共享消费者保持原规则。

## 人工可操作入口与验证

提供本人可见 UNKNOWN 清单、原任务查询、证明/意见审计、已核实事实采纳和未生效重试入口；不提供任意JSON强制成功按钮。高权限运维视图有明确租户/范围授权，完整原文和凭据不得因查看待办而泄漏。

先真实PG/HTTP关键红测，再独立评审：旧发送线程迟到、原ACK丢失、重复/冲突许可、同key并发、证明错误/缺失、权限收窄、原审批过期、已取消、后续代回调、outbox重投、重试计量以及取消三态互不混同。至少一条实际engine+skill进程外部计数纵切；测试协议fixture与真实供应商/MCP/K8s验收分别记录。

具体内部报文与新增迁移在实施阶段固定并向消费者发布。该计划不声称完成实现、生产IAM或外部协议验收。
