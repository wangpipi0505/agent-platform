# G5长运行观察消费者

现有WebApp/SDK只消费一条SSE连接；服务端55秒正常EOF或stream_reset后，任务可能仍在运行。以已经受理的runId持续只读观察，不重新提交任务，不把观察断线当成取消。

新增共享observeRun循环：读一段认证SSE→读取权威status并应用快照→非终态时按已应用快照水位重连。只有有ID的事实推进游标，chunk/控制帧不推进；CURSOR_EXPIRED/AHEAD给出的水位须先取并应用快照才采用。401/403/404等不可恢复鉴权/资源错误停止，状态服务连续故障有界重试，AbortSignal终止观察；观察器不包含创建/取消写请求。

Chat与原生SDK共用该流程，保持等待确认、最终快照替换临时文本和输出验证提示；恢复期间保持当前任务身份与发送禁用状态。服务端reset不承诺补回缺失token，最终输出始终由权威快照替换。先验证EOF、游标、失联/权限、确认与中止，再检查真实组件/后端连接。
