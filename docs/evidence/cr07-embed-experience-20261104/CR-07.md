# CR-07 嵌入体验精确读取与配置一致性

2026-11-04。网关集成票据仅新增绑定应用的GET experience与运行semantic-results精确读口（后者继续经现有run归属/应用核对），不开放管理面或跨应用。应用体验接口优先使用已验Actor环境，显式查询不能越出票据环境；缺省不再把staging用户导向production。

SDK体验请求只使用合法environment选择器，401/403明确显示，不记作正常无体验；解析只接本应用、当前会话/显式提议一致的配置。服务器体验给出的configReleaseId会成为新会话提议，服务端仍是最终裁决；新会话等待体验加载，已有会话先恢复固定引用再读取，不混用当前新体验。

必要功能检查两轮：

1. 实红：IntegrationExperiencePolicyTest断言本应用体验可读，生产策略返回false，1失败；reactor在此停止，尚未运行app测试。
2. 修复后 `mvn -o -pl platform-gateway,app-management -am -Dtest=IntegrationExperiencePolicyTest,ExperienceEnvironmentTest -Dsurefire.failIfNoSpecifiedTests=false test`，JDK21：网关1/1、app已验环境2/2通过；前端 `vitest run tests/assistant-experience-policy.test.ts` 3/3通过，覆盖配置相等/不同、跨应用、401/403、环境注入。

没有放宽断言；未启动整栈、真实HTTP/SDK浏览器场景或全量验收。类型与打包在在途组件合入后统一做必要编译检查。
