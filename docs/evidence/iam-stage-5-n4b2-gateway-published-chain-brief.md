## 实际信任和注册

唯一允许业务入口是REQUEST dispatch、精确POST /admin/apps/[A-Za-z][A-Za-z0-9_-]{0,63}/runs。拒绝任何query（包括空query）、编码/分号/双斜杠/尾斜杠别名、其它method/path及FORWARD/INCLUDE/ASYNC/ERROR再入。只允许真实TrustedJwtDecoder已验的门户user且具有platform.access；明确Bearer来源，重复/非Bearer/ApiKey、integration/service/workload及cookie/query身份不能取得证明。浏览器自报tenant/principal/version/digest/服务URL等不能影响目标和根。健康若需要须按实际明确映射单列，不加通配豁免。

GatewayIngressBoundary拥有具体安全filter及全局无include/exclude的MappedInterceptor；私有构造request proof由owned filter直接验证真实原token后创建，preHandle再核实际handler并进入可单次领取状态，controller在任何legacy调用前领取。不能只信SecurityContext中的public Jwt，不能用公开VA/壳record假装请求权限；异步代码不重绑ThreadLocal，只保留已验源token、SubjectKey和必要本地期限。controller不得用CGLIB的this等同容器proxy。

request proof绑定owned filter实际看到的request anchor。后续安全/Servlet过滤器会包装请求：preHandle/controller沿ServletRequestWrapper.getRequest有限逐层找同一anchor，引用相等；找不到、环或超过固定层数拒绝。不能任意解到最底层后丢失owned anchor。proof还要绑定同一个boundary、REQUEST/method/rawpath、实际handler、未失效/未领取；afterCompletion、afterConcurrentHandlingStarted、filter finally幂等清理。异步回调不携可复用request proof。filter安排在实际受控安全链合适顺序，OncePerRequestFilter默认跳过ASYNC/ERROR，不能只注册dispatcher就宣称会运行；使用明确能覆盖/拒绝这些dispatch的实际filter。

GatewayProxyIngress（准确同义小类型可）只允许serviceId=gateway、真实cn.agentplatform.gateway.api.GatewayController声明的proxy(HttpServletRequest,HttpServletResponse):void。全部RequestMappingInfoHandlerMapping都要检查，包括secondary：/admin/**与/v1/**两条ANY各一次、同一真实已解析handler bean和Method，无第三ANY、缺项、替代bean/子类绕过。使用HandlerMethod.createWithResolvedBean().getBean引用相等，AopUtils.getTargetClass和getMostSpecificMethod核实际类型/方法。普通Ingress禁止ANY/wildcard的规则不动；app/engine全局ServiceAuthorization不动。gateway其余disabled普通catalog行仍由同一真实boundary全局默认拒绝，不给gateway创建服务能力。

需要验证真正安装的FilterChainProxy及唯一预期catchall SecurityFilterChain：不能只找一个守卫bean，也不能容忍先匹配的空/其它链。过滤器实例/相对顺序、实际链matcher和全局MappedInterceptor必须对应同一个boundary。Finite launcher排除SecurityFilterAutoConfiguration生成的第二Delegating注册，保留显式安全链装配。用极小具体final registration把同一final FCP传给真实ServletContext.addFilter，成功add/configure后保存context、实例和配置快照；verifier对照该记录、实际注册名/URL及当前受控配置。Servlet API metadata不返回installed filter实例或全部实际dispatcher/order，不做这种虚假证明，不用Tomcat内部反射。

## 有限异步代理与两个授权步骤

真实GatewayController.proxy保持void签名。使用WebAsyncUtils.getAsyncManager(req).getAsyncWebRequest取得MVC已经安装的AsyncWebRequest，登记timeout/error/completion，设剩余timeout并由它startAsync，再取实际AsyncContext；不能裸req.startAsync却让MVC误判已同步完成。实际req.isAsyncSupported为前提，不能只据一个bean默认值宣称成立。回调不做同步阻塞读取/HTTP/Future.get/join/flushBuffer/output.close。

PublishedRunProxy拥有每请求私有Exchange，READING→UPSTREAM→WRITING→TERMINAL、单次状态转换/终止、源信息、buffer、owned worker Future、当前HTTP可取消句柄及固定单调截止。本轮技术上限建议proxy业务入口开始5000ms（不包含之前JWT验证，不称整条物理连接硬截止），请求/成功JSON各2MiB；metadata及engine每跳最多2000ms、connect1000ms，并取总剩余时间较小值，任何chunk/阶段不能重置总预算。若实际固定API不支持此落点，先向root说明再选更小具体办法，不加运行参数框架。这些是软件运行边界，不是项目时间安排。

ReadListener只在isReady且未finished时读小块，Content-Length预检加真实字节累计，超限413、非法JSON/重复键/尾随/非object/压缩或不支持媒体类型拒绝，保留合法原body字节和原运行协议不暗改字段。onAllDataRead只能提交一次后续工作，读取未完成/超时先终止时不调用metadata/main/engine。禁止同步读线程+Future超时假称实际socket read可中断；Tomcat NIO阻塞读会忽略interrupt，InputBuffer.close也只是标记。

后续owned worker顺序：以私验SubjectKey的tenant和安全code做真实PublishedMetadataClient.lookup原门户token→固定app metadata-only endpoint；拿实际versionId/versionNo/stored candidate SHA构造app-version root；以同一原门户token独立exchangeGatewayPublishedRun打开main（不用metadata grant/main resume/forward替代）；核subject/root等与lookup相符，requireVerified后只向固定engine POST /admin/apps/{code}/runs。app只收app票据、engine只收engine票据，原token仅给配置的authority，绝不发app/engine；忽略客户端目标/身份/version headers。Main只一次，不retry/recreate/replay。实际lookup与engine目标均https固定origin；loopback仅显式隔离fixture允许127.0.0.1，不用不安全全局TLS设置。

gateway专用成熟transport同时承接metadata GET和engine POST，明确关闭自动retry、redirect、cookie、authcache/challenge重发、压缩，禁止由响应Location/其他URL选择目的地。每次真实请求都保留实际可取消句柄；取消与句柄安装竞态要处理（终止后才安装则立即取消），读取按累计大小/剩余预算，worker最终退出有独立finally/latch证据。不要由Future.isDone/cancel返回推断实际worker/socket已经退出。既有metadata严格4字段/4KiB/2s不弱化；确需保留原错误分类，按实际endpoint与原用例核定，错误body不透传。只给有限状态401/403/409/503及明确传输失败安全错误，不把所有下游失败伪成200或回显rawbody。

响应先完整有限缓冲并严格核JSON/媒体/大小/无额外trailers，阻止SSE/压缩/redirect/cookie等成为输出旁路。N4b1 proof在真正POST发送紧前、完整buffer后、每次实际成功JSON写前均requireVerified；异步worker的check不能冒称实际HTTP send检查，必要沿用Apache实际发送拦截机制而不是在排队前核一次。WriteListener按isReady分小块写，复核terminal/总deadline/proof，直到无待写数据再complete；禁止listener内阻塞flush/close。第一次成功写前过期则成功payload字节0，可安全回固定403；headers/body一旦提交只能停止剩余字节，不能谎称改回403或撤销已发送数据。

terminate幂等，取消owned Future和active HTTP、释放源/buffer并停止后续动作；真实worker finally退出单独观测。timeout/error/disconnect/close竞态和late callback均不得再次POST或写已复用request/response。组件close拒新请求、取消活动工作并在回调以外有限等待自己拥有的worker。Common IAM调用保留其实际有界get与finally取消的能力/限制，不改其wire/transport；不得把proxy Future中断说成所有JWK/authority网络硬停止。

固定Tomcat10.1.41的Http11OutputBuffer.end可能执行flush(true)，Servlet公开API不能给任意恶意慢读端保证物理socket硬截止；不加内部强拆adapter。慢客户端fixture必须自己在有限时间真实关闭，再证明自有worker/handler退出和测试资源回收，准确区分逻辑停止写出与物理连接结束。Servlet async timeout扫描也不是毫秒实时调度；本地单调复核阻止超期后新的业务动作，不承诺绝对实时socket SLA。引擎可能已受理run而gateway响应后续到期，不能据失败响应声称PG run=0或外部执行已撤销。
